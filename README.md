# 🛍️ retail-clustering-ml — Сегментация клиентов онлайн-ритейла

Этот проект анализирует поведение клиентов интернет-магазина с помощью методов машинного обучения. Цель — сегментировать клиентов на основе их покупательского поведения и создать понятные клиентские профили.

## 📁 Структура проекта

- `homework_3.ipynb` — Jupiter Notebook с кодом анализа и кластеризации
- `data/Online Retail.xlsx` — датасет с транзакциями интернет-магазина
- `explanation.docx` — построчное объяснение кода
- `README.md` — описание проекта

## 🎯 Цели

- Очистка и предобработка данных
- Создание признаков Recency, Frequency, Monetary (RFM)
- PCA для снижения размерности
- Кластеризация (KMeans, DBSCAN)
- Визуализация и интерпретация сегментов
